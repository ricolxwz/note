## Q3

1Gbps = 10^9 bps = 10^3 Mbps = 10^6 Kbps. 1s = 10^3ms = 10^6 mus = 10^9 ns. 首先, 我们来回顾一下CSMA/CD. CSMA/CD的核心工作机制是在自己说话的过程中, 竖起两只耳朵听别人时候也在说话. 一旦监测到碰撞, 立刻中止传输. 如果信道空闲, 就立即开始发送帧, 如果信道忙碌, 就等到信道空闲再发送, 使用1-persistent策略. 如果监测到别的节点也再传输, 发送jam signal, 大约48bit. 冲突发生后, 会从{0, 1, 2, ..., 2^m-1}中随机选择一个数k, 然后等待k*512bit times后再进行重试. 

考察的是CSMA-CD. k=462. 网络的最大速率R=10^9bps. 物理传输速率位2*10^8m/s. 我们直接套用公式效率=1/(1+5*t_prop/t_trans). 这个效率的意思是说, 我们链路上的实际带宽是最大带宽(速率)的多少. 这里的t_prop是最长的线路的传输时间, 最长的线路长度是300*2+2*462=1524m, t_props=1524/2*10^8=7.62mus. 数据包的大小是500*8=4000bit. t_trans = 4000/(10^9)=4mus. 所以根据效率的公式, 我们可以计算出效率=0.095=9.5%. 所以实际可用的带宽是9.5%*10^9=0.095Gbps. 每台主机每秒发送的数据量是4000*1000=4000000bit. 那么2N台电脑每秒产生的数据量是8N Mb. 8N要小于等于95, 得到N=11, 所以电脑的数量为22.  

如果hub1被替换为了switch, 那么说明有两个collision region. 减少了数据的流动. 我们要计算的是t_props和t_trans, 对于t_props我们要先得到他的max span. 由于变成了两个冲突域, 我们只要计算在同一个冲突域内的最大长度, 我的k=462, 所以比600大, 所以最大长度是762. 所以t_props = 762/2*10^8=3.81mus. t_trans还是不变的, 因为L和R都没有改变, 仍然是4mus. 所以效率=0.1735. 所以带宽就是0.1735Gbps. 每一边每秒的流量是4N(本地电脑产生的流量)+4N*1/4(对面传过来的流量) = 5N Mb. 所以5N<=173.5, 得到N最大为34, 所以最多可以有68台电脑. 

## Q4

这题考察的是Slotted ALOHA, 先来回顾一下什么是Slotted ALOHA, 他是在纯ALOHA协议的基础上, 通过将时间切碎来减少冲突发生的概率. k=2. 他说在每个时间间隙里面, 一个节点独立发送的概率是0.1. 那么在这个时间间隙里面, 只有一个节点在发送的概率符合二项分布, 概率为(5 1)*(0.1)^1*(0.9)^4=0.328. 没有节点发送的概率是 (5 0)*(0.1)^0*(0.9)^5=0.59. (1) A在某一个slot成功的概率是(0.1)*(0.9)^4=0.06561, 那么在第6个slot成功的概率符合几何分布, 为(1-0.06561)^5*0.06561=0.0467. (2) 这个就是0.328. (3) 前面没有发送可能有两种原因, 一种是空闲, 一种是冲突, 在一个时间间隙中, 出现这两种情况的概率是1-0.328=0.672. 概率为(0.672)^5*(1-0.672)=0.0449. (4) Slotted ALOHA的效率就是一个时隙中出现发送的概率, 即0.328.

## Q11

这题考察得是EstimatedRTT, TCP必须设置一个超时计时器来控制什么时候重传. 但是这个时间比较难确定, 核心是因为RTT是波动的, 超时太短会导致不必要的重传, 超时太长会导致丢包后反应太慢. 测量从发出报文到收到确认的时间, 作为SampleRTT, 如果发生了重传, 就不要把时间算进去, 单次测量不稳定, TCP会计算一个加权平均的EstimatedRTT: EstimatedRTT = (1 - α) * EstimatedRTT + α * SampleRTT. 有了平均值还不够, 还得考虑安全边际, 这是因为如果网络波动幅度非常大, 安全边际就要留大一点, 我们会计算一个波动幅度(DevRTT): DevRTT = (1 - β) * DevRTT + β * |SampleRTT - EstimatedRTT|. 最后, 我们就可以计算出最终的超时重传时间: TimeoutInterval = EstimatedRTT + 4 * DevRTT. 这里α通常取0.125, β取0.25.

(1) 这个很简单, 计算出SampleRTT01234, 就可以计算得到SampleRTT5了. 最后得到结果149.23ms. (2) 递推公式推导, 不太可能考. (3) 同上.

## Q17

RSA也是一块重要的知识点. 首先会选取两个非常大的质数p和q, 然后计算n=p*q, 计算z=(p-1)*(q-1), 然后选取e, 使得e和z互质, 且e<z; (n, e)为公钥; 然后选取d, 使得e*d mod z = 1, 私钥为(n, d). 加密过程是非一条大小小于n的信息m, c = m^e mod n. c就是加密后的数据. 解密也是m = c^d mod n. 

(1) 我们会比较n = pq = 437和z = 396. (2) 选取一个数e使得e和z是互质的, 且e<z. 我们取e=13, 13和396是互质的, 并且13<396. (3) m=62. 这是我们要加密的信息, c=m^e mod n. c = 62^13 mod 437 = 209. (4) 由于m'=c^d mod n=62. 所以m'=m. (5) 因为, 如果n很小的话, 很容易发现质数p和q, 那么就可以算出z和n, 那么已经知道了公钥, 也就是知道了e, 就能通过(ed) mod z = 1计算出私钥d.
