---

* 关闭Hyper-V, WSL, 这会使宿主机运行在一个虚拟化层之上
* 电源模式: 最佳性能, 当然, 缩肛大户intel就不必了
* 控制面板-硬件和声音-电源选项-编辑计划设置-更改高级电源设置-处理器电源管理-最大处理器状态-设置为99%
* 控制面板-硬件和声音-电源选项-选择电源按钮的功能: 更改当前不可用的设置, 关闭快速启动
* 任务管理器-启动应用: 可以选择是否关闭启动项
* 高级显示器设置: 刷新率最高
* 显示卡: 应用陈旭的自定义设置, 添加应用, 然后GPU首选项选择高性能, 把经常用的应用都放进去
* 就近共享: 关闭
* USB: 关闭USB节电模式
* 其他鼠标设置: 提高指针精度开启
* 游戏模式: 关闭
* windows安全中心: 内存完整性关闭
* Bios: Intel-VT, AMD-SVM虚拟化技术统统关闭
