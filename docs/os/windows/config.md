title: 配置
comments: true
---

* 关闭Hyper-V, WSL, 这会使宿主机运行在一个虚拟化层之上
* 电源模式: 最佳性能, 当然, 缩肛大户intel就不必了
* 控制面板-硬件和声音-电源选项-编辑计划设置-更改高级电源设置-处理器电源管理-最大处理器状态-设置为100%
* 控制面板-硬件和声音-电源选项-选择电源按钮的功能: 更改当前不可用的设置, 关闭快速启动
* 任务管理器-启动应用: 可以选择是否关闭启动项
* 高级显示器设置: 刷新率最高
* 显示卡: 应用陈旭的自定义设置, 添加应用, 然后GPU首选项选择高性能, 把经常用的应用都放进去
* 就近共享: 关闭
* USB: 关闭USB节电模式
* 其他鼠标设置: 提高指针精度开启
* 游戏模式: 关闭
* windows安全中心: 内存完整性关闭
* Bios: Intel-VT, AMD-SVM虚拟化技术统统关闭
* 隐私和安全性: 全部不勾选
* 调整Windows的外观和性能: 选择调整为最佳外观
* 内存: BIOS里面打开XMP, 频率提高到高水平, 或者可能叫做DOCP, EXPO
* 去掉重复延迟
    1. 键盘属性中, 重复延迟最短, 重复速度最快
    2. 辅助功能中确保筛选键关闭
