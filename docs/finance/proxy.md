## 智能套利

智能套利是一种加密货币的交易策略, 旨在通过对冲市场波动来赚取稳定收益. 其核心原理包括两点:

1. Delta中性策略: 在现货市场买入某种资产(多头仓位), 同时在合约市场做空相同数量的该资产(空头仓位). 这样, 无论价格如何涨跌, 这两个方向相反的仓位损益可以相互抵消, 从而大幅降低价格波动带来的风险.
2. 收益来源: 主要通过在持仓期间收取永续合约的资金费用实现利润. 资金费率通常每隔8小时结算一次, 当资金费率为正时(通常意味着多头力量更强), 多头持仓者需要向空头持仓者支付资金费用. 通过这种方式, 智能套利策略可以在市场波动中实现稳定的收益.

当套利策略不再适用于市场行情(例如资金费率持续为负)时, 应停止策略. 此时, 系统会自动为您平仓所持有的现货和合约头寸.

### 预估年化

我们可以选择"放大投资额", 其实就是杠杆. 1.5 X: 这代表您将使用1.5倍的杠杆来放大投资额. 也就是说, 如果你投入1000 USDT, 系统会帮你再借入500 USDT, 总共用1500 USDT来执行套利策略. 套利年化这个收益率是基于全部的投资额(上面的1500USDT)来计算的, 借币年化是你为借入资金所需支付的成本利率, 这个利息只在你借来的那部分(500USDT)上计算. 预估总年化是最终预估的净年化收益率, 也就是扣除所有成本后, 你自己的本金能获得的年化回报.

举个例子:

"情况一: 无杠杆 (1x)":

*   你的本金: 100元
*   总投资额: 100元
*   策略收益: 100元 * 7.387% = 7.387元
*   你本金的收益率: 7.387元 / 100元本金 = 7.387%
*   借贷成本: 0元 (因为没借钱)

在这种情况下, 界面会显示:

*   套利年化: +7.387%
*   借币年化: 0%
*   预估总年化: +7.387%

"情况二: 1.5倍杠杆":

*   你的本金: 100元
*   总投资额: 150元 (100元本金 + 50元借款)
*   策略收益: 150元 * 7.387% = 11.08元
*   你本金的收益率: 11.08元 / 100元本金 = 11.08%

在这种情况下, 界面会显示:

*   套利年化: +11.08%
*   借币年化: -3.50%
*   预估总年化: +7.58%

### 开仓价差率

"开仓价差率" (Opening Price Spread Rate) 指的是在你执行套利策略的那一刻, 永续合约的价格和现货的价格之间的百分比差异. 简单来说, 它告诉你, 你做空合约的价格比你买入现货的价格是高了还是低了, 高/低了多少.

开仓价差率 = (永续合约价格 - 现货价格) / 现货价格 * 100%

这个价差率代表了你建立套利仓位的"初始成本"或"初始收益".

比如:

*   卖出 BTCUSDT 永续 (合约价): `111,135.8`
*   买入 BTC/USDT (现货价): `111,186.1`

根据公式计算: (111,135.8 - 111,186.1) / 111,186.1 * 100% ≈ -0.045%. 这个 -0.045% 就是你的开仓价差率.

这代表了什么?

*   负价差率 (像这个例子里):
    *   意味着你做空亏价了. 你买入现货的价格(`111,186.1`)比你做空合约的价格(`111,135.8`)要高.
    *   这相当于你一开仓, 就立即有了一个 0.045% 的账面浮亏. 这个浮亏就是你为了吃到后续"资金费率"而付出的"入场费".
    *   你未来赚到的资金费率, 必须首先填补掉这 0.045% 的亏损, 剩下的才是你的净利润.

*   正价差率 (理想情况):
    *   如果合约价格高于现货价格, 比如你做空的价格是 `111,200`, 买入现货是 `111,186`.
    *   这意味着你开仓即盈利! 你"高卖低买", 在一开始就锁定了价差带来的收益.
    *   这部分初始收益, 会和你未来赚到的资金费率叠加, 成为你的总利润.

### 开仓条件

开仓价差率: `-0.091%`:

*   这行是您自己设定的一个"阈值" (Threshold) 或 "门槛".
*   含义: "我最多只愿意接受 `0.091%` 的开仓亏损(入场费). 如果开仓时的价差比这个数字更差(例如 `-0.1%`, 亏损更大), 那就不要开仓. "
*   您设定这个值, 是为了控制入场成本.  `-0.091%` 就是您能容忍的最高成本.

当前开仓价差率: `-0.041%`:

*   这行显示的是此刻市场上的实时价差.
*   含义: "如果现在立刻下单, 你的开仓成本(浮亏)会是 `0.041%`. "

单笔最大下单金额: `1,000 USDT`:

*   这也是您设定的一个安全限制.
*   含义: "当条件满足并执行开仓时, 单次下单的总金额不要超过 `1,000 USDT`. "
*   这是一种风险管理措施, 防止因市场波动或操作失误导致一次性投入过大资金.

## 网格

"网格"在交易领域, 特指网格交易策略(Grid Trading). 您可以把它理解为一个预先设定好价格阶梯的自动化买卖系统. 在一个特定的价格范围内, 设置一系列等距离或等比例的价格线(就像一张网). 当价格下跌到某条线时, 就自动买入一份. 当价格上涨到某条线时, 就自动卖出一份.

当网格超出设定的价格上下限时, 会发生两种完全不同的情况:

1. 价格 超出上限 (俗称"跑赢网格"或"踏空")

    *   发生情况: 当价格持续上涨, 突破你设定的最高卖出价时, 意味着你网格里设置的所有卖单都已成交. 你手里的币已经全部卖光了.
    *   结果:
        *   盈利: 你成功赚取了整个网格区间内的所有波动利润. 此时网格策略会暂停, 因为无币可卖.
        *   踏空: 这是最大的风险. 如果价格继续一路上涨, 后续所有的涨幅都与你无关了, 因为你已经提前"下车"了.

    简单说: 币卖飞了, 赚了网格的小钱, 错过了趋势的大钱.

2. 价格 跌破下限 (俗称"跌穿网格"或"被套")

    *   发生情况: 当价格持续下跌, 跌破你设定的最低买入价时, 意味着你网格里设置的所有买单都已成交. 你用来买币的钱已经全部用完了.
    *   结果:
        *   浮亏: 你网格账户里的资产已经全部换成了不断贬值的币, 此时你会处于浮动亏损状态. 网格策略会暂停, 因为无钱可买.
        *   套牢: 如果价格继续下跌, 你的浮动亏损会越来越大. 你只能选择"装死"等待价格涨回你的网格区间, 或者"割肉"卖出止损.

    简单说: 钱花光了, 抄底抄在了半山腰, 并被牢牢套住.

| 情况 | 结果 | 核心风险 |
| :--- | :--- | :--- |
| 价格 > 上限 | 币全部卖出, 网格利润落袋为安.  | 踏空, 错失后续的巨大涨幅.  |
| 价格 < 下限 | 钱全部花光, 买入了一堆贬值的币.  | 套牢, 承受巨大的浮动亏损.  |

### 移动网格

"移动网格"是现货网格策略的升级版, 专门为了应对单边上涨行情而设计. 如果说普通网格是一张固定不动的渔网, 那么移动网格就是一张会自己向上移动的渔网.

### 简单赚币分配

* 没开启这个功能时(传统网格):

    * 所有的工人都被派到生产线上. 一部分工人等着价格下跌时"买入", 另一部分工人等着价格上涨时"卖出".
    * 问题: 如果当前价格在中间, 那么离价格最远两端的工人(比如负责在价格暴跌或暴涨时才交易的)就一直站着没事干, 他们的时间(资金)就被浪费了.

* 开启这个功能后(智能分配):

    * "活跃区间": 工厂管家只让离当前价格最近的, 随时可能需要交易的工人们在生产线上待命. 这个范围就是"活跃价格区间".
    * "闲置资金"去理财: 对于那些离当前价格很远, 暂时不会轮到他们交易的工人, 管家会派他们去外面做兼职(投入"简单赚币"), 来赚取额外的工资(利息).
    * "动态调整": 当市场价格移动, 快要轮到某个做兼职的工人上场时, 管家会立刻把他从兼职岗位上自动召回(从"简单赚币"中赎回), 让他回到自己的生产线岗位上(挂单).

### 预设开始条件

这些是用来设置网格策略启动时机的高级选项, 简单来说, 就是决定你的机器人什么时候开始运行, 而不是创建后立即开始.

1. 未预设: 这是默认选项. 你点击"创建策略"后, 机器人会马上开始买入底仓并铺设网格订单, 立刻进入工作状态.
2. 价格触发: 当市场价格达到你设定的某个价位时, 再启动.
3. RSI触发: 当技术指标RSI达到你设定的数值时, 再启动. 这是一种更高级的择时策略. RSI(相对强弱指数)是衡量市场"超买"或"超卖"的常用指标. 通常RSI低于30被认为是超卖区(可能要反弹上涨).  通常RSI高于70被认为是超买区(可能要回调下跌). 你可以设置"当4小时级别的RSI指标低于30时启动". 这样做的目的是想在市场技术性超卖, 可能出现反弹的"黄金坑"时自动开启网格, 捕捉上涨行情.
4. TradingView 信号 (TradingView Signal): 你在TradingView上设定好你的独门买入信号, 然后通过一个叫做"Webhook"的技术, 让TradingView在信号出现时"通知"你的网格机器人. 机器人收到通知后就会立即启动. 这相当于把机器人的启动开关完全交给了你在TradingView上自定义的复杂策略.

### 网格模式

| 模式 | 核心特点 | 每格利润特点 | 适用行情 |
| :--- | :--- | :--- | :--- |
| 等差网格 | 价格差固定 | 利润金额固定 | 窄幅震荡市 |
| 等比网格 | 价格比例固定 | 利润率固定 | 宽幅震荡或趋势市 |

什么是宽幅或者窄幅?

| 项目 | 窄幅网格 | 宽幅网格 |
| :--- | :--- | :--- |
| 价格区间 | 小 (如 ±10%) | 大 (如 ±50%) |
| 跑出网格风险| 高 | 低 |
| 交易频率 | 高 | 低 |
| 每格利润 | 小 | 大 |
| 资金利用率 | 高 | 低 |
| 适用行情 | 明确的, 稳定的横盘震荡市 | 波动剧烈, 方向不明的长期行情 |
| 操作心态 | 追求效率, 需要盯盘调整 | 追求省心, 可以长期放置 |

### 自动预留保证金

这个选项是期货网格或杠杆网格中一个非常重要的安全设置, 用来防止您的整个策略被强制平仓(爆仓).

1. ✅ 勾选自动预留保证金(安全模式)

    *   意思: 系统自动给您的赛车装上一个"备用油箱".
    *   工作方式: 除了主油箱的油(用于开仓的保证金), 系统还会额外锁住一部分备用油. 当主油箱快耗尽时(出现爆仓风险), 系统会自动打开备用油箱, 补充燃料, 防止赛车熄火.
    *   优点: 非常安全. 大大降低了因为价格突然剧烈波动而导致整个策略被强制平仓的风险.
    *   缺点: 资金利用率稍低, 因为有一部分"备用油"被锁住, 不能用于开更大的仓位.

2. ❌ 不勾选(专业/高风险模式)

    *   意思: 您决定不装备用油箱, 只用主油箱的油.
    *   工作方式: 您自己决定要加多少油, 可以用最少的油跑最远的路(最大化资金效率). 但如果油快耗尽, 系统不会自动帮你, 需要您自己手动加油(手动增加保证金).
    *   优点: 资金利用率最高. 所有资金都用于交易, 可以开更大的仓位或用更高的杠杆.
    *   缺点: 风险极高. 如果您没有及时手动补充保证金, 一次剧烈的价格波动就可能让您的策略直接爆仓, 所有资金血本无归.
