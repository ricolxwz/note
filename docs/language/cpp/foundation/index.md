# 基础

## 推荐学习路径

1. 构建
2. 类型
    - 数据类型
    - `const`类型
    - `sizeof`运算符
    - 左值右值(重点理解`const className& other`可以同时接受左值和右值)
3. 指针
    - 地址运算符
    - 使用引用传参
4. 函数
    - 作用域
    - 循环
    - 函数不能在其他函数内部
5. 数组
    - 数组offset
    - 向函数传递数组
6. 指针
    - 内存分配
    - 函数指针
    - 智能指针(重点理解`weak_ptr`)
7. 对象
    - 类的介绍
    - 权限修饰符
    - 构造函数和析构函数
    - 拷贝构造函数
    - 拷贝赋值操作符
8. 函数
    - 操作符重载
    - 返回值优化(特别注意RVO触发的条件)
