# 基础

## 推荐学习路径

- (构建) 构建系统
- (类型) 数据类型
- (类型) const类型
- (类型) sizeof运算符
- (类型) 左值右值: 重点理解`const className& other`可以同时接受左值和右值
- (指针) 地址运算符
- (指针) 使用引用传参
- (函数) 作用域
- (函数) 循环
- (函数) 函数不能在其他函数内部
- (数组) 数组offset
- (数组) 向函数传递数组
- (指针) 内存分配
- (指针) 函数指针
- (指针) 智能指针: 重点理解`weak_ptr`
- (对象) 类的介绍
- (对象) 权限修饰符
- (对象) 构造函数和析构函数
- (对象) 拷贝构造函数
- (对象) 拷贝赋值操作符
- (函数) 操作符重载
- (函数) 返回值优化: 特别注意RVO触发的条件
- (对象) 成员初始化列表
- (对象) struct的使用
- (对象) RAII
- (对象) 移动构造函数和移动赋值操作符: 重点是对于将亡值的理解, 我们在传递完参数之后就用不到他们了
- (对象) 规则 5/zero/3: 教你怎么正确的写出一个好的C++类
