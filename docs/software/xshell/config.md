* 选项
  * 常规
    * 启动时打开的会话: 添加一个"实验室"的会话
    * 开始选项: 打开启动会话
  * 终端
    * 勾选将选定的文本自动复制到剪贴板
    * 如果要粘贴多行: 选择直接粘贴到您的终端中
  * 更新: 全部关闭
  * 高级
    * 终端
      * 取消勾选"请使用智能选择按钮..."
    * 窗口
      * 勾选"在全屏模式下隐藏滚动条"
      * 取消勾选"全屏模式下使用标题栏"
    * 会话
      * 取消勾选"会话终止时断开连接"
      * 取消勾选"退出xshell时确认断开连接"
      * 取消勾选"连接终止时还原为本地shell"
      * 取消勾选"最后一个标签关闭时退出Xshell"
* 默认对话属性
    * 隧道
      * 取消勾选"转发X11连接到"
    * 终端
      * 终端大小, 列100, 行40, 连接时重置端子尺寸
      * 取消勾选"输入/输出终端时滚动到底部"
      * 勾选"按键滚动到底部"
    * 外观
      * 修改字体
