## 设置中文

1. 找到安装目录
2. 修改fontforge.bat文件
3. 设置`set LANGUAGE=zh_CN`

???+ warning "注意"

    如果按照这样的方式进行汉化, 软件无法识别中文文件名, 需要修改为英文之后尝试打开

## 字体调试

1. 把英文字体打开
2. 元素-字体信息-OS/2-特征, 所有的选项设置为"任何"
3. 元素-字体信息-通用-全字大小, 设置为1000
4. 文件-生成字体, 选择TrueType, 取消勾选保存前确认, 点击选项, 取消勾选TrueType渲染提示, 点击确定, 点击Generate, 关闭窗口, 点击不保存
5. 中文字体如法炮制

## 合并字体

1. 打开调试后的英文字体
2. 元素-合并字体, 选择调试后的中文字体
3. 自偶矩选择"是"
4. 导出, ...., 居然闪退了? 垃圾软件!
