---
title: 合并字体
comments: true
---

1. 打开两个字体软件
2. 选择英文字体
3. 全选, 然后复制, 记住Glyphs的数量
4. 点击中文字体
5. Insert-Glyphs-By Number, 输入刚才记住的数量, Glyphs选择At top
6. Edit-Paste Special, Destination选择Selected glyphs, Data中勾选Glyph name, All layers, Outline, Decompose composites, Code-point, Add code-points, 点击OK
7. 选中Unused, 全选, 删除
8. 在中文字体下, File-Export font as-Export as desktop font, 然后确认, 就可以在Documents/fonts文件夹下找到合并好的文件
