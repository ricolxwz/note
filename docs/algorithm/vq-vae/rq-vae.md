# RQ-VAE

## 摘要

对于高分辨率图像的自回归(AR)建模, 向量量化(VQ)将一幅图像表示为离散码序列. 序列越短, AR模型在考虑码之间的长程依赖时计算开销越低. 然而, 作者指出, 就码率–失真(rate-distortion, 即码率与重建误差之间的权衡)而言, 现有VQ方法难以同时缩短码序列并保持图像高保真度. 为此, 本研究提出了一个两阶段框架, 由Residual-QuantizedVAE(RQ-VAE)和RQ-Transformer组成, 用以高效生成高分辨率图像. 在固定码本大小的前提下, RQ-VAE能够精确逼近图像特征图, 并将图像表示为一组堆叠的离散码映射. 随后, RQ-Transformer通过预测下一堆码来学习下一个位置的量化特征向量. 得益于RQ-VAE的精确逼近, 该方法可将256×256图像压缩为分辨率8×8的特征图, 从而显著降低RQ-Transformer的计算成本. 因此, 该框架在无条件和条件图像生成的多项基准上均优于现有AR模型, 生成高质量图像时的采样速度也明显更快.
