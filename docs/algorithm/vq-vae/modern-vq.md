## 多码本结构

* 层次化码本: 典型的代表是**VQ-VAE-2**. 该模型在原始VQ-VAE基础上加入了分层离散表征: 利用多个层次的码本(如顶层和底层)来编码图像的不同粒度特征, 从而提升表示能力. 顶层码本负责补货全局粗略信息, 底层码本编码细节, 缓解了单一码本难以兼顾全局和细节的局限. 这种多层码本结构有效提升了图像重建质量和生成多样性, 以ImageNet图像生成上能产生高保真且多样性的结果. 还有一个是Williams等人提出的**HVQ-VAE**. HVQ-VAE采用逐层训练每个VQ编码器/解码器栈, 实现了更高的压缩率, 此外它们引入了码本重置机制, 在训练中将"死码字"用高频码字加噪声重初始化. 这一策略在一定程度上减少了码字未被利用的问题, 但由于直接用高频码字拓展, 新的码字分布空间较窄, 提升有限. 总体而言, 层次化多码本结构通过增加离散表示层数来扩大表示空间, 在图像生成和压缩任务中取得了显著效果(如OpenAI的DALL-E等模型也采用了层次离散VAE作为图像tokenizer).

* 并行多码本/产品量化: 另一类思路是将编码向量分块, 由多个并行的码本分别量化, 组合形成更大的离散空间. 典型的工作是**PQ-VAE**, 最早用于语音离散表示.
