## 自然涌现

自然涌现就是指随着大模型的规模(参数量), 训练数据量和计算资源的增加, LLMs突然展现出的一些他们在训练的时候并未被明确教导或者编程的全新能力或者行为. 常见的例子包括: In context learning, CoT, Zero-shot learning等等. 核心特点是, 1. 非线性出现: 这些能力并非是随着模型的规模提升而线性增强, 而是到某个特定的规模或者复杂度阈值之后, 突然并且显著地涌现出来; 2. 未被明确编程/训练: 研究人员并没有直接的数据集或者任务来教授这种能力, 而是模型从训练数据总结, 归纳, 泛化出来的; 3. 复杂性产生: 他们是模型内部复杂结构和海量知识相互作用的结果; 4. 增强泛化能力: 涌现使得大模型能够执行更加复杂, 更加多样化的任务, 包括他们从未直接见过或者以特定方式训练过的任务. 

## 大模型是怎么训练出来的

LLM训练是一个多阶段, 资源密集而且复杂的过程, 核心目标是让模型能够理解, 生成和处理人类预言. 整个过程主要分为以下阶段: 1. 数据准备, 训练数据通常包含来自互联网的文本(如网页, 书籍, 维基百科, 论坛), 代码, 对话记录, 甚至可能是多模态数据(文本和图像, 视频结合). 数据量通常达到数万亿个Token. 然后, 对数据进行去重, 过滤低质量内容, 去除偏见或者有毒内容, 同时确保数据覆盖不同主题, 风格和预言, 以提高模型的泛化能力和安全性; 2. 预训练: 几乎所有的现代大模型都基于Transformer架构, 这种架构通过注意力机制能有效捕捉文本中的长距离依赖关系. 模型在没有人工标注的情况下进行训练, 常见的目标是下一个词预测(GPT)或者是掩码预言建模(BERT). 预训练需要庞大的计算资源, 训练时间长达数周甚至数月. 预训练完成后, 模型就具备了强大的基础预言理解, 生成能力和丰富的世界只是, 但是他的行为可能尚未符合人类的价值观; 3. 微调和对齐. 一般性有两种方法, 一种是SFT(指令微调). 使用高质量的, 人类编写的指令-响应对数据集对预训练模型进行微调, 这些数据会教会模型如何理解和遵循命令, 例如"总结这段文字", "写一首关于xxx的诗". 这一步让模型从"预测下一个词"到"理解并响应指令". 第二种是基于人类反馈的强化学习(RLHF). 这是提高模型"人类对齐"的关键步骤, 使模型输出更加符合人类的偏好, 更加安全, 更加无害. 给出同一个问题, 让模型生成多个不同的回答, 然后由人类标注者对这些回答进行排序, 使用这些人类偏好数据训练一个奖励模型, 目标是学习人类的偏好模式, 能够为任何模型生成的回答打分. 利用奖励模型作为奖励函数, 通过强化学习算法(如PPO, DPO等)进一步微调预言模型. 目标是生成能够获得高奖励分数的回答. 

## Functional Calling能力如何训练

大模型的函数调用能力, 是让模型能够理解用户意图, 并主动生成符合外部工具或者API接口规范的结构化调用指令. 他的训练是一个多阶段, 精细化的过程, 主要是在通用大模型预训练的基础上, 通过精心构造的训练数据和监督微调(SFT)来实现的. 模型需要被教会如何阅读和理解外部工具的功能定义. 在训练数据中, 可用的函数(工具)的详细定义通常会以结构化的形式, 如Json Schema, 描述函数名, 描述, 参数以及类型作为输入的一部分提供给模型. 模型需要学习解析这些定义, 将其融入上下文, 从而直到哪些工具可用, 每个工具的功能以及如何正确调用他们. 为了让模型学会何时以及如何调用函数, 需要大量的用户意图-期望行为配对数据, 这些数据通常以以下的方式生成: 1. 人工标注, 少数高质量的人工标注示例, 用于展示复杂的意图理解, 工具选择和参数提取; 2. 合成数据生成: 这是扩展数据规模的主要方式. 利用已有的大模型或者规则引擎, 结合提供的工具Schema, 自动生成大量的用户查询, 对应的期望输出(**可能是某个工具的JSON格式调用, 也可能如果信息不足, 需要模型生成追问, 有可能是无需工具, 简单的自然语言回复**), 会覆盖这些多种情况. 然后, 使用上述构建的用户查询+可用工具定义->期望输出数据集, 对预训练模型进行SFT微调. 模型通过学习这些示例, 掌握**意图识别(准确判断模型何时希望模型调用工具), 工具选择(在多个可用工具中选择最合适的那一个), 参数提取(从用户的自然语言中准确抽取关键信息, 并填充到函数的参数中, 生成正确的结构化调用格式), 非工具场景判断(当用户意图不涉及任何可用工具的时候, 模型应该返回自然的文本回复)**. 进一步的, 为了优化模型的函数调用行为, 使其更加的可靠, 安全, 符合人类的偏好, 可以通过RLHF解决模型可能出现的幻觉(如生成不存在的参数, 调用错误的工具)或者在不适当的时候调用工具. 

## 微调的方案有哪些

微调是指大模型在经过大规模通用数据预训练之后, 使用特定任务或者特定领域的数据集进一步训练模型, 使其适应特定应用场景或者优化特定指标的过程. 他的目的是为了让模型在保持通用能力的基础上, 更加精准, 高效地完成特定任务, 更好地和人类意图对齐. 微调地方法主要分为以下几类:

1. 全参数微调: 将预训练模型的所有层和所有参数都解冻, 然后使用目标任务的数据对这些参数进行梯度更新, 这相当于在预训练模型的基础上进行了一次完整的再次训练. 理论上能达到最大的性能, 因为模型的所有能力都被允许对新任务进行调整, 对于与预训练任务差异较大的任务, 效果可能比较显著. 但是他的计算资源开销巨大, 并且可能有灾难性遗忘的风险, 部署成本较高(每个新任务都需要存储一个完整的模型副本). 适用数据量相对较大, 且资源充足, 追求极致性能的时候. 
2. 参数高效微调(Parameter-Efficient Fine-Tuning, PEFT): 冻结预训练模型的大部分参数, 只训练少量新增或者修改的参数, 或者通过某种方式简介影响模型的行为, 大大降低了计算资源需求和存储成本. 有点是计算资源和存储开销大幅降低, 训练速度快, 显存占用少, 有效缓解灾难性遗忘的问题, 每个任务只需要存储少量可训练的适配器参数, 部署更加灵活. 常见的方法有
    1. LoRA(Low-Rank Adaption), 在Transformer的特定层旁边添加小的, 可以训练的低秩矩阵, 微调的时候只训练这些小的矩阵, 他们和原始权重矩阵相加完成更新. 
    2. Prefix-Tuning, 在模型的输入序列或者Transformer的每一层前面插入少量可训练的虚拟Prompt Token(即前缀), 模型主题参数保持冻结. 微调的时候只训练这些前缀的嵌入向量. 
    3. Adapter Tuning: 在Transformer的每一层(通常在多头自注意力层和前馈网络层之后)插入小的神经网络模块(适配器), 只训练这些适配器层的参数. 

    适用场景是资源受限, 数据集较小, 模型规模巨大, 需要快速迭代和多任务部署, 且对性能有较高要求但是又不想进行全量微调的场景. 

3. 指令微调(SFT): 使用大量高质量的指令-响应对数据集来训练模型. 这些数据以用户指令+期望回应的形式实现, 旨在教会模型如何理解并遵循人类的各种提示(如总结, 翻译, 回答, 特定格式生成等). 显著提升模型的遵循能力, 交互自然度, 可控性, 是实现模型Helpfulness(有用性)和Follow Instruction(遵循指令)的关键一步. 几乎所有通用聊天机器人和助手模型的训练流程中都包含这一步, 它可以与全参数微调或者PEFT结合使用. 
4. 对齐微调(Alignment Fine-tuning): 旨在使模型的行为和人类价值观, 偏好和安全伦理规范对齐, 使其输出更安全, 更加无害, 更加符合预期. 常见的方法有基于人类反馈的强化学习(Reinforcement Learning from Human Feedback, RLHF), 能够学习细致入微的人类偏好, 显著提高模型的安全性, 有用性, 遵循指令能力和减少幻觉. 适用于对模型的安全性, 公正性, 用户体验和行为一致性有较高要求的场景(如通用聊天助手, 内容创作等). 

## Transformer的架构, Encoder和Decoder是什么

Transformer是一种由Google在2017年提出的深度学习模型, 它彻底改变了序列建模领域, 尤其是自然语言处理(NLP). 它最核心的创新是完全摒弃了传统的循环神经网络(RNN)和卷积神经网络(CNN)结构, 而是完全依赖于注意力机制(Attention Mechanism)来捕捉序列中的依赖关系. Transformer的提出是为了解决传统RNN在处理长序列时遇到的长期依赖问题和计算效率问题. 通过注意力机制, 模型可以同时关注输入序列中的所有部分, 并行处理, 从而大大提高了训练数据和处理长序列的能力. Transformer主要由两个主要部分构成: 编码器和解码器, 每个部分包含多层相同的子层堆叠. 

编码器的作用是将输入序列(如一句话或者一段文本)转换成一种连续的, 丰富的表征. 它理解输入序列的语义信息和上下文关系. 其内部结构(每一层)主要包含: 

* 多头自注意力机制(Multi-Head Self-Attention): 这是编码器的核心, 它允许模型在处理序列中的每一个词的时候, 都能关注到输入序列中的所有其他词, 并根据他们的相关性赋予不同的权重. 多头表示它并行地执行多个注意力计算, 从而可以在不同的子空间中学习到不同的信息, 增强模型的捕获能力. 
* 前馈神经网络(FNN): 一个简单的两层全连接网络, 对自注意力层的输出进行非线性变换. 它对每个位置(词)独立操作. 
* 残差连接(Residual Connections)和层归一化(Layer Normailization): 每个子层(自注意力层和FFN)的输出都会与它的输入进行残差连接(Input + Sublayer(Input)), 然后进行层归一化. 这有助于缓解梯度消失问题, 加速模型训练, 并提高稳定性. 

输入序列的每个词首先被转换为嵌入向量(Word Embeddings), 然后加上位置编码(Positional Encoding)以保留词序信息. 这些向量随后进入编码器堆栈, 通过自注意力机制捕获词之间的上下文依赖, 并由FFN进行进一步处理, 最终输出一个包含序列所有信息的高维向量序列, 作为解码器的"记忆".

解码器的作用是根据编码器输出的上下文表征, 以及已经生成的部分输出序列, 逐步生成目标序列(如翻译后的文本或摘要). 其内部结构主要包含: 带掩码的多头自注意力机制, 这个和编码器中的自注意力类似, 但是有一个关键区别, 掩码(Masking). 在生成当前词的时候, 模型只能关注目标序列中已经生成的词, 不能偷看未来的词, 以模拟顺序生成过程. 编码器-解码器注意力机制, 这一层是解码器和编码器交互的地方, 它允许解码器在生成输出序列的每一个词的时候, 能够关注到整个输入序列的上下文表征(由编码器输出的记忆), 从而将输入信息有效地融入到输出生成中. 前馈神经网络(FFN)和编码器中的FFN功能类似. 残差连接: 和编码器中的作用相同. 

## 什么是分词器

分词器是大语言模型(LLM)与人类可读文本之间的"翻译官".  它的核心任务是将原始的, 连续的文本(例如句子, 段落)切分成模型能够理解和处理的较小单元, 这些单元被称为"词元"(Token). 同时, 它也能将模型生成的词元序列重新组装成人类可读的文本. 

深度学习模型, 包括大模型, 本质上是处理数值的数学函数. 他们无法直接理解和操作原始文本字符串. 分词器将文本转换为一系列数字ID, 这些ID对应着模型词汇表中的词元. **如果以单个字符为单位, 词汇表会很小, 但是序列会非常长, 模型处理的效率比较低, 且语义信息分散. 如果以整个单词作为单位, 词汇表会非常大, 对于罕见词或者是新词处理困难(OOV问题), 且需要大量空间来存储词嵌入. 分词器旨在找到一个平衡点, 将常见的词汇作为一个token, 而不常见的或者复杂的词汇拆分成更小的, 有意义的字词单元.** *通过拆分字词, 即使模型在训练过程中没有见过某个完整的词, 它也能通过识别字词或者推断其含义或处理它.*

分词器的主要工作流程: 1. 文本切割(tokenization): 将原始文本字符串切分为一系列的词元; 2. 词元到ID的映射(Token to ID Mapping): 将每个词元映射到其在分词器词汇表中的唯一数字ID; 3. ID到词元的映射(ID to Token Mapping), 将数字ID序列转换回刻度的词元, 进而组合成文本. 

常见的分词算法有:

* BPE (Byte Pair Encoding)字节对编码: 从字符级别开始, 统计训练语料中相邻字节对出现的频率, 将最常见的字节对合并为一个新的token. 不断重复这个过程, 直到达到预设的词汇表大小或者不再有高频字节对. 简单高效, 能有效处理OOV问题, 词汇表较小. 广泛用于GPT系列, BERT, RoBERTa等早期和中期模型. 
* WordPiece: 类似于BPE, 但他不是合并最常见的字节对, 而是合并能够使最终语料的似然度增加最大的字符和词. 在处理中文, 日文等没有空格分隔的语言时候表现更好. 如BERT和DistilBERT.
* SentencePiece: 不仅处理单词内部, 还处理单词之间的空格. 它将原始文本视为一系列Unicode字符, 空格也被视为一个可学习的字符(通常用_表示). 从而能够更好地处理多语言和不同分词习惯的文本, 它可以基于BPE或者Unigram算法. 在T5, LLaMA, GPT-2/GPT-3/GPT-4中有应用. 

## Embedding是啥, 用的哪个模型

Embedding是一种将高维, 离散的数据例如词语, 句子, 图像, 用户ID等映射到低维, 连续向量空间的技术. 具体到NLP领域, 特别是大模型中, Embedding的核心思想是:

1. 将文本数据数值化: 计算机无法直接理解人类的语言, Embedding将词语, 短语, 句子甚至是整个文档转换为一串具有实数值的数字(即向量).
2. 捕捉语义和语法关系: 在这个低维向量空间中, 那些语义或者语法上相似的词语或者概念, 他们的向量在空间中的距离也会比较接近(例如, 国王的向量会和女王, 男人, 女人的向量相对接近). 这种相似性通常通过向量之间的余弦相似度来衡量. 
3. 降低维度: 原始文本数据维度较高且比较稀疏. Embedding将其压缩到几百到几千维的稠密向量, 即节省存储, 又便于模型处理. 
4. 提供上下文信息: 特别是现代的大模型, 其Embedding往往是上下文敏感的, 这意味着同一个词, 在不同的句子中, 其Embedding向量往往不同, 从而能更好地捕获多义词的含义. 

我们通常会根据具体的应用场景和需求, 选择或训练合适的Embedding模型. 我们一般会在两种模型中选择:

1. 基于Transformer架构的上下文敏感Embedding模型: 包括像BERT, RoBERTa, GPT系列(虽然GPT更加注重生成, 但是他内部的表示可以用作Embedding), 以及专门为Embedding设计的模型如OpenAI的text-embedding-ada-002, Google的LaMDA/PaLM/Gemini系列提供的高质量Embedding API. 这些模型通常是通过预训练学习得到的, 能够根据词语在句子中的具体上下文, 生成不同的Embedding向量. 预训练在海量的文本的数据上, 具备强大的语义理解能力, 适用于多种下游任务. 通常用于语义搜索, 文本匹配, 推荐系统, 智能问答召回等需要精确语义理解的场景.
2. 专门优化的亲两级或者特定的域Embedding模型: 如sentence-transformers库中的模型, 如Sentence-BERT, MPNet等. 这些模型在Siamese网络或者Triplet网络架构下, 被专门训练来生成语义丰富的句子Embedding. 如果我们的应用在某个非常专业的领域(如医疗, 法律), 我们会考虑使用该领域的大量文本数据对通用Embedding模型进行二次微调, 或者训练全新的Embedding模型, 以捕捉领域特有的术语和关系. 对于句子或短文本的Embedding, 这类模型通常比大型的通用LLM推理更快, 资源消耗更低. 效果好:  在特定任务(如句子语义相似度)上, 可能比直接从通用LLM中提取的Embedding表现更好. 通常用于大规模的文本聚类, 分类, 相似度查询, 以及对实时性或资源消耗有较高要求的场景. 

## 什么是A2A
